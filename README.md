# Handball – Spvgg Ilvesheim

Ergebnisse, Tabellen, Live-Stand und Liga-Statistik (Torschützen, 7m, Strafen) der Männer Bezirksliga Rhein-Neckar.

**App:** https://awo38.github.io/handball/

Daten: handball4all.de. Die Statistik wird automatisch per GitHub Actions aus den offiziellen Spielberichten erzeugt (`scripts/update-stats.mjs`, Ligen in `config.json`). Details in `ANLEITUNG.md`.
